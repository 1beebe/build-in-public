The Interviewer V2, as a workflow

For builders who have something to share but stall at the blank page. V2 asks for the work in one field, holds one conversation, lightly removes speech debris while preserving meaning and voice, and saves only the Ideas they approve. Orange-outlined nodes make every AI call explicit; all other nodes use ordinary code, APIs, or human judgment.

V2 mental model

Give it context → have one conversation → keep the useful thoughts. Configuration appears only when it is needed.

One sign-in

Buffer remains the only connected account. GitHub reads public data without authentication; non-GitHub builders describe the work instead.

One voice path

GPT-Live is the spoken experience. Typing is the accessible fallback, not a second voice system. Starting to type pauses live voice so one transcript writer stays authoritative.

AI call map

Read context: no AI; GitHub and Buffer API fetches only. The fetched context enters the model when the conversation begins. Spoken interview: OpenAI GPT-Live 1, one streaming session. Typed interview: DeepSeek Flash through MindStudio, one call after each answer. Find my Ideas: Claude Sonnet 5.5 through MindStudio, one call at the end.

Authorship boundary

The harvest may remove fillers, join and reorder the builder's thoughts, but it cannot invent a claim, feeling or detail. The builder reviews every card and writes the eventual post.
