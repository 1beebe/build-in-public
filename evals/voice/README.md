# Voice test clips

Synthetic speech (espeak-ng, mbrola us2 voice) for the scripted voice test: each entry in
`deadend-clips.json` is one answer as base64 Ogg/Opus, in order. The test page plays them into
the live GPT-Live session in place of a microphone. Lines: "Hi, can you hear me?", then the
`deadend` persona's answers from `../personas.json`.
